SMART TRAFFIC SIGNAL SYSTEM

1. Extract this ZIP file.
2. Open index.html in Chrome or Edge.
3. The simulation starts automatically.
4. Vehicles move from all four directions. The active green lane releases
   vehicles one by one. When 2 remain, the next direction turns yellow.
   After the remaining vehicles pass, that direction turns green.
5. The browser voice announces each signal change.
6. Use Pause/Resume or Restart when needed.

This is an educational simulation only, not a real-world traffic controller.
